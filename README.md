## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- pnpm or npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Ejack172/adda247couponcode.com.git
cd adda247couponcode.com

# Install dependencies
pnpm install
# or
npm install
```

### Running Locally

```bash
# Development mode
pnpm run dev

# Production build and start
pnpm run build
pnpm run start
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
